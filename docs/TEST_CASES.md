## 1. 方針

- 本書は `docs/REQUIREMENTS.md` と `docs/SPECIFICATION.md` を基準にした手動テストケース集
- 対象は PC ブラウザで動作する IssueBoard 全体
- GitHub API 連携を前提とするため、必要に応じてテスト用リポジトリと PAT を用意する

## 2. 前提条件

- `.env` に `VITE_REPO_OWNER` と `VITE_REPO_NAME` が設定されている
- テスト対象リポジトリに以下のラベルが存在する
- 優先度ラベル: description に `priority` を含むラベル
- カテゴリラベル: description に `category` を含むラベル
- ステータスラベル: description に `status` を含むラベル
- テスト用 PAT は `repo` スコープを持つ
- アプリは `npm run dev` で起動済み

以下のような Issue があると主要ケースを確認しやすい。

| TC-DATA-02 | 3日以内の課題 | 🟡 今週 | 処理中 | 👥 採用労務 | 3日以内 | 設定あり | コメントあり |
